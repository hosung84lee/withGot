# src/skills — 런타임 Agent 용 스킬 (약관 담당)

- 이 폴더는 **제품이 실행 중에 Agent 에게 주는 스킬(도구)** 이다. Claude Code·Codex 의 스킬이 아니다.
- 기본: 구조화된 약관을 조 단위로 보여주는 도구(목차, 조 본문, 별표 본문), 사고보장 JSON 조회 도구.

## (추가 목표) 보험금 계산 프로그램 생성 Skill
1. 기본 범위가 아니다. 고정 계산 툴(`src/mcp_server/`)이 끝난 뒤 시간이 남을 때만 만든다.
2. 입력은 사고보장 JSON, 출력은 `src/data/generated/` 아래의 계산 코드다. 다른 위치에는 쓰지 말 것.
3. 생성 코드는 `src/mcp_server/AGENTS.md` 의 계산 규칙(결정론, int 금액, 규칙 값 하드코딩 금지, steps 와 근거)을 따라야 한다. 이 규칙을 스킬 지시문에 그대로 넣는다.
4. 생성 직후 `src/data/golden/claims/` 로 자동 검증하고, 실패하면 "검토 필요"로 표시한다.
