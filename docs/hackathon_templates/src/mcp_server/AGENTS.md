# src/mcp_server — 보험금 계산 툴 규칙 (보험금 담당)

1. 계산은 결정론적 순수 함수로만 한다. **LLM 호출 금지.** 같은 입력이면 항상 같은 결과가 나와야 한다.
2. 금액은 int(원). 비율 계산은 분자/분모 정수로 하고 마지막에 한 번만 나눈다 (float 로 금액을 계산하지 말 것, 원 미만 처리 방식은 H0 확정).
3. 기간·비율·한도·공제·KCD 범위 같은 규칙 값은 사고보장 JSON 에서 읽는다. 하드코딩 금지.
4. 결과(⑤)에는 단계별 계산 과정(`steps`)과 각 단계의 약관 근거를 함께 담는다. 근거는 사고보장 JSON 의 `source`·`extra_sources` 를 그대로 쓰고 새로 만들지 말 것.
5. 사고보장 JSON 의 `special_conditions` 설명(글)은 코드로 해석하지 말 것. AI 판단 항목(②)이 있으면 그 결과를 쓰고, 없으면 `decision: "review"` 로 낸다.
6. 툴 docstring 은 LLM 이 읽는 설명이다. 언제 쓰는 툴인지, 입력이 무엇을 뜻하는지 한국어로 명확하게 쓴다.
7. 기본 툴: `calc_fixed_rate`(정액: 면책·감액·최초 1회·합산), `calc_actual_cost`(실손: 공제·보상률·한도·자기부담 상한).
   계산 정답 시나리오(`src/data/golden/claims/`)로 테스트한다.
