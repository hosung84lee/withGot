# src/agent — LLM 호출 규칙

- `policy/` 는 약관 담당, `claim/` 은 보험금 담당, `llm_client.py` 는 약관 담당이 만든다. 상대 폴더는 수정하지 말 것.

## 규칙
1. 모든 LLM 호출은 `llm_client.py` 를 거친다. 요청·응답은 `src/data/cache/` 에 저장하고, `REPLAY=1` 이면 캐시만 사용한다(데모 안전장치).
2. 프롬프트는 `prompts/*.md` 파일에서 읽는다. 코드에 긴 프롬프트 문자열을 두지 말 것.
3. 출력은 structured output 으로 받고 `src/schema/` 모델로 검증한다. 검증에 실패하면 에러 내용을 붙여 최대 2회 재시도하고, 그래도 실패하면 에러로 올린다.
4. **LLM 에게 금액·날짜를 계산시키거나 지급 여부를 결정하게 하지 말 것.** 프롬프트에도 이 금지를 명시한다.
5. **추측 금지.** 스키마에 없는 항목은 값을 만들어내지 말고 `escalations` 에 "항목 / 원문 위치 / 스키마 추가가 필요한 이유"로 담는다.
6. LLM 이 준 id 와 `status` 는 믿지 않는다. id 는 코드가 다시 매기고, `confirmed` 는 근거 검증(코드, `workflow/policy/`)으로만 정한다.

## AI 판단 (claim)
- 입력: 판단 항목 정의(`schema/judgment.py`) + 관련 서류 부분 + 관련 약관 조항. 판단 항목과 관계없는 서류는 넣지 말 것.
- 출력: 결과·설명·소스(`result`, `description`, `refs`)는 필수다.
- 판단에 필요한 서류가 없거나 근거가 불충분하면 `unknown` 으로 내고 사람 검토 대상으로 표시한다.
