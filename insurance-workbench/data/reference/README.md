## 확인한 사항
- 파일의 PDF 헤더와 페이지 수를 확인했습니다.
- 영수증 작성 예시와 세부산정내역 빈 서식을 이미지로 직접 확인했습니다.
- 영수증 예시는 본문이 이미지이므로 OCR이 필요합니다.
- 세부산정내역 서식도 텍스트 추출이 되지 않아 OCR이 필요합니다.
- sources.json의 failed 항목은 검색했지만 확보하지 못한 자료입니다.
- 페이지 추출본은 원본 파일명과 1부터 시작하는 PDF 페이지를 이름에 보존했습니다.

## 개발 시 구분
이번에 받은 영수증과 세부내역서는 같은 진료 건의 서류 쌍이 아닙니다.
빈 세부내역서에는 치료나 금액이 없어 치료 인식·문서 합계 대조 정확도 검증에는 부족합니다.
다음에는 별도 합성 쌍을 작성하거나 권한이 있는 비식별 실제 서류 쌍을 확보해야 합니다.
합성 자료를 만들면 synthetic으로 표시하고 웹에서 수집한 자료와 분리합니다.

첨부 삼성생명 약관과 웹 수집 삼성화재 약관은 회사·상품·버전이 다릅니다.
약관마다 별도 policy_id와 version을 부여하고 계산 규칙을 섞지 않습니다.
2016년 약관은 현재 상품의 구약관으로 간주하거나 직접 개정 비교하지 않습니다.

공개 다운로드 가능 여부와 재배포·변형·모델 학습 이용 허락은 별개입니다.
현재는 원본 보존·출처 확인용으로 수집했으며 공개 저장소 업로드나 학습을 수행하지 않았습니다.
외부 OCR·LLM 전송 전 자료의 개인 식별 항목과 이용 조건을 확인합니다.
