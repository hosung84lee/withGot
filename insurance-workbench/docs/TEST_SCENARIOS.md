## 재실행

개발 서버와 API를 실행한 상태에서 아래 명령을 실행한다. Windows는 설치된 Chrome을 사용한다.

```text
uv run ruff check apps/api
uv run pytest
npm --prefix apps/web run build
npm --prefix apps/web run test:privacy
```

빌드 미리보기에서 다시 검사하려면 `npm --prefix apps/web run preview -- --port 5174`로 실행한 뒤 `BOJANGIT_URL`을 `http://127.0.0.1:5174`로 지정한다.

PDF-04는 포함된 가상 영수증의 암호화 사본을 만들어 실행한다. API-02의 실제 API 확인은 리디렉션을 따라가지 않는 클라이언트로 진행하며, 응답 헤더와 서버 로그에 가상 환자번호가 남는지 확인한다.
